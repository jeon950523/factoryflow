# ADR-016 — 독립 업무 규칙 검증 경계

상태: TASK-025 제안 구현, CI 대기.

SSOT 불변조건과 공개 API 계약을 검증 정본으로 사용한다. 검증기는 앱 코드, 프론트 구현, 기존 테스트 헬퍼를 import하지 않고 Node 내장 모듈과 runner-local HTTP만 사용한다. 기존 UI 테스트는 제거하지 않는다. 격리 MySQL과 실제 Spring Boot를 사용하고 운영/공개 데모에는 쓰지 않는다. 별도 Actions 결과를 유지하고, GitHub required check는 보호 설정 확인 이후 별도 적용한다. 합성 oracle 음성 대조군과 앱 변이 테스트를 구분한다.
