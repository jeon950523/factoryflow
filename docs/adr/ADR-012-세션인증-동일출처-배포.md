# ADR-012 — 서버 세션 인증과 동일 출처 API

상태: 선택 / 검증 진행 중

## 목적
FactoryFlow 단일 VM + Vercel SPA 환경에서 인증되지 않은 제조 API 접근을 차단한다.

## 결정
1. JWT localStorage 대신 Spring Security 서버 HttpSession + HttpOnly JSESSIONID.
2. 관리자와 조회자 역할을 나눈다. 관리자만 모든 제조 쓰기 및 사용자 계정 관리를 수행할 수 있다.
3. CSRF는 HttpSessionCsrfTokenRepository와 XOR request handler로 검증하며, Vue는 GET /auth/csrf로 받은 요청용 토큰을 모든 변경 요청에 전송한다.
4. 초기 계정은 서버 환경변수만 사용하며 평문 비밀번호나 재사용 가능한 기본 패스워드를 Git에 넣지 않는다. BCrypt 비용 12.
5. Vercel/Oracle 외부 배포 시 Vercel 동일 출처 /api rewrite를 통해서만 세션 쿠키를 사용한다. 서로 다른 출처에서 credentials를 허용하는 CORS 구성은 현재 채택하지 않는다.
6. SESSION_COOKIE_SECURE=true, HTTPS, Reverse Proxy Forwarded 헤더, CSRF와 세션 고정 방어 실환경 검증 전 외부 공개 금지.

## 장단점
- 장점: 단일 서버에 간단하고 로그아웃 시 서버에서 세션을 폐기한다. 브라우저 LocalStorage에 비밀 저장을 피한다.
- 단점: 서버 재시작 시 세션 상실, 확장 시 공통 세션 저장 필요, CSRF 방어 필수.
- 포트폴리오 기준으로 적절하나 인증 테스트 합격만으로 실무 배포 준비가 끝난 것은 아니다.

## 추가 보안 게이트
- 로그인 시도 rate limit, 계정 잠금·비밀번호 재설정, session fixation·CSRF 자동 테스트.
- 실제 TLS reverse proxy와 Cookie Secure/HttpOnly/SameSite 검증, 비밀 관리, DB 백업.
- 원격 무인증 API 차단과 관리자 계정 관리권한 검증.
