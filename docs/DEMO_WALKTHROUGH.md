# FactoryFlow 브라우저 체험 가이드

## 어디서 실행하나?
- Vercel: **https://factoryflow.kro.kr**
- 별도 계정이나 암호 없이 체험할 수 있도록 구성. 데이터는 이 **브라우저만의 IndexedDB**에 저장된다.
- 이 사이트는 **데모용 시뮬레이션**이다. Java21·Spring Boot·MySQL을 실제로 호출하지 않는다.

## 5분 제조 시연 순서
1. **품목 · BOM**: 원자재 3종과 완제품 산업용 제어 박스, 원자재별 소요량을 확인한다.
2. **재고 · 입고**: 산업용 강판/조립 볼트/절연 수지의 현재고·예약고와 LOT를 확인한다. 직접 원자재 입고도 가능하다.
3. **생산지시 · 품질**: 초안 `WO-DEMO-READY`를 선택한다. 계획 10개, 강판 20/볼트 40/수지 10이 필요하다.
4. **자재 예약**: 필요한 전량을 FIFO LOT에서 예약한다. 현재고는 그대로, 예약고만 증가.
5. **생산 시작 → 생산 완료**: 예약된 자재를 실제 (데모 모델 내) 차감하고 검사를 기다린다.
6. **품질검사 확정**: 합격 수량만 완제품 QC_PASS LOT로 입고한다.
7. **완제품 출고**: QC_PASS LOT에서 FIFO로 출고하고 이동 내역을 살펴본다.
8. **새로고침**: 변경된 내역이 해당 브라우저에 남아 있는지 확인한다.
9. **샘플 초기화**: 상단 안내 배너에서 클릭해 처음 샘플 상태로 되돌린다.

## 데모에서 보장하지 않는 것
- 다른 PC·브라우저의 데이터와 공유되지 않는다. 브라우저 데이터를 지우면 기록이 삭제될 수 있다.
- 인증 UI는 자동 체험 사용자일 뿐. Spring Security/BCrypt/CSRF를 데모가 검증하는 것은 아니다.
- 재고 롤백, LOT FIFO 및 요청 중복 방어는 데모 JS 엔진이 **시뮬레이션**한다. 실제 MySQL 기반 동시성·트랜잭션 증거는 백엔드 Testcontainers 및 실DB CI 테스트에서 확인한다.

## 개발 모드와 서버 모드
- 로컬 `npm run dev`: 실제 Java 백엔드 API.
- 프로덕션 `npm run build`: 기본 IndexedDB 데모.
- 실서버 준비 후 `VITE_DEMO_MODE=false` 빌드 + API 리버스 프록시, Secure Cookie, TLS, CSRF 운영 QA를 완료해야 서버 전환 가능.
