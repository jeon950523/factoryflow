## 1. 검증 방법

실서버를 띄우는 프로젝트 내부 테스트와 별도로, **GitHub Actions의 실제 Chrome이 외부 공개 도메인에 직접 접속**하는 스모크 테스트를 추가했다. `/movements?itemId=1`, `/items?itemId=4`, `/shipments?id=1` 각각의 SPA 직접 접근과 데이터 표·업무 링크를 점검한다. 요청 HTTP 코드 및 브라우저 페이지 오류를 확인한다.

공개 Vercel 사이트는 이 브라우저에서만 동작하는 IndexedDB 데모이며, 실DB 서버의 제조 트랜잭션은 기존 `fullstack-ui-ci.yml`에서 별도 검증한다. 테스트는 조회 전용이며 생산/재고를 수정하지 않는다.

## 2. 확인된 결과

| 항목 | 관측 결과 |
|---|---|
| 외부 호스트 `/movements` HTTP 응답 | 200 |
| 공개 Chrome 스모크 | 2/2 PASS (한글 폰트 적용 재실행) |
| 품목·BOM 페이지 | 전체 품목 표 + 선택된 BOM 원자재 구성표 표시 |
| 완제품 출고 페이지 | 출고 기록 표 + 실제 LOT ID/배분 수량 표 표시 |
| 재고 이동 이력 | 원자재 입고 +50, 소모 −10, 업무 참조 링크 표시 |
| 브라우저 실행 오류 | 테스트의 `pageerror` 수집 결과 없음 |
| 데모 페이지의 실서버 `/api/v1/` 호출 | 테스트 관측 결과 없음 |
| 페이지 전체 화면 증거 | 3개 PNG를 GitHub Actions 아티팩트로 저장 |

## 3. PC 화면 육안 검수

**좋은 점**

- 1440px PC 레이아웃에서 왼쪽 제조 메뉴, 상단 업무명, 검색/처리 도구, 전체 너비 업무표, 선택 상세가 일관된 구조로 정렬된다.
- 품목/BOM은 목록 아래 상세 구성표, 출고는 이력 아래 LOT 차감 내역, 이동은 처리 시각·증감량·업무 참조 정보를 한눈에 보여준다.
- 이동 수량의 유입·유출을 +/−와 별도 색으로 구분하고, 서버에 없는 출고 LOT 코드 대신 제공된 LOT ID를 표시한다.
- 데모 데이터와 실서버 데이터가 다르다는 안내가 화면에 명확하게 표시된다.
- 스크린샷의 한글이 처음에 네모로 표시된 현상은 CI Ubuntu의 한글 글꼴 부재로 확인되었고 `fonts-noto-cjk` 설치 후 정상 표시된다. 사이트 코드의 폰트 수정은 필요하지 않았다.

**보완 후보 (이번 QA 범위에서 직접 수정하지 않음)**

- 작은 글씨의 보조 설명, 회색 안내 문구, 비활성 페이징 버튼은 가독성·명암 대비를 측정해 개선할 가치가 있다.
- 실제 사용자 Windows Chrome 환경, 확대 비율 125~150%, 키보드 Tab 순서와 모달 초점 복귀는 공개 사이트 스모크 성공만으로 완전 검증했다고 주장할 수 없다.
- `frontend/README.md`의 인증 미구현/실제 API 전용이라는 오래된 안내는 현재 인증·데모 구성과 어긋나므로 다음 문서 최신화 때 수정해야 한다.
- 현재 확인한 것은 1440px 한 구성이며 실제 사용자의 UI 전반 시각 품질 평가에는 다양한 데이터량과 인터랙션 테스트가 추가로 필요하다.

## 4. 검수 및 책임 범위

이번 PR은 배포된 애플리케이션·백엔드·DB를 수정하지 않는다. QA 전용 Chrome 워크플로, 테스트 설정, 테스트 코드 및 검수 기록만 추가한다. 공개 도메인에 접근하지 못하는 대화 실행 환경과 달리 GitHub-hosted Chrome에서 HTTP 200 및 실제 DOM 렌더링을 확인했으므로, 접속 환경 차이를 사이트 장애로 오판하지 않았다. 프로덕션 배포 성공, 브라우저에서의 콘텐츠 렌더링, Windows PC 수동 검수는 서로 다른 증거로 구분한다.

## 5. 향후 리팩터링 관점

- **기능:** 로그인·팝업·모달의 키보드 포커스 관리와 실제 화면 내 조회 동선/문구를 별도 QA 작업으로 분리한다.
- **효율:** 외부 도메인 스모크를 모든 소스 커밋마다 실행하면 Vercel 배포 반영 시점보다 먼저 검사할 수 있다. 자동으로 항상 성공을 선언하지 않고, 배포 상태 확정 후 수동 재검증할 수 있도록 `workflow_dispatch`를 제공한다.
- **유지보수:** 외부 도메인과 샘플 ID는 테스트 설정에 집중시키고, 실DB 동작 여부는 기존 E2E와 분리한다. 과도한 공통 추상화는 도입하지 않는다.
